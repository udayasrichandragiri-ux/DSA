 Programs

 1. Linear Search

File: `linear_search.cpp`

This program searches for a target element by checking each array element one by one.

Time Complexity: `O(n)`

2. Binary Search

File: `binary_search.cpp`

This program searches for a target element in a sorted array by repeatedly checking the middle element.

Time Complexity: `O(log n)`

 3. Bubble Sort With Swap Count

File: `bubble_sort_swaps.cpp`

This program sorts an array in ascending order using Bubble Sort and counts the total number of swaps.

Time Complexity: `O(n^2)`

 4. Reverse an Array

File: `reverse_array.cpp`

This program reverses an array in place without using another array.

Time Complexity: `O(n)`

 5. Student Marks Analyzer

File: `student_marks_analyzer.cpp`

This mini project:
- Takes marks of N students as input.
- Calculates the average score.
- Sorts marks in descending order.
- Displays the top three marks.
